Almonium · design constitution · v2

The rulebook

Feed this file to any AI agent as initial context before it touches Almonium. It supersedes the previous design-system analysis, which specified cyan for premium, a system-font stack for type, and gradient on every action button — all three are now prohibited.

Scope: almonium-fe (Angular · Less · Tailwind · Taiga UI), email-templates (Thymeleaf), brand assets.
Not in scope: Almonium Books, an internal admin tool, which may diverge freely.

The five laws

Everything below is derived from these. If a rule and a law conflict, the law wins.

1

No brand hue exists that is not on the emblem's ramp. Status colours are the only exception.

2

Gradient means premium and nothing else. Every other action is solid.

3

Calm by default, warm at the edges. Surfaces holding content are quiet; personality lives only where there is nothing to read.

4

Two type families, self-hosted. Literata reads, IBM Plex Sans operates. No system stacks, no third family.

5

Every panel is a card. Same radius, same shadow, white on cream — the reader, a book, a word and a setting are instances of one object.

Status — deliberately off-ramp

Alarm and success must interrupt. A status colour that harmonises with the brand fails at its only job. These four are a principled exception to law 1 and are not to be "brought on-brand".

#16BA7F success #fa4666 error #ea6644 warning #E7F8F2 success ground
Prohibited

Pure black anywhere. #00d1ff, #8a2be2, or any cyan. #120222 (blue-violet). Brand-coloured third-party logos. Any new hue invented to solve a local problem — extend the ramp's ends instead. Raspberry for plan limits: a paywall boundary is not an error.

2 · Type

Literata

Wordmark aside: page titles, section headings, book titles, all reading content, the word on a card, large numerals in stats.

Variable weight, full Cyrillic — required by the UA/RU wedge. Reader default; user may override from three options, not a font menu.

IBM Plex Sans

Nav, buttons, chips, badges, form labels, tooltips, counts, eyebrows, all UI prose.

Cyrillic + Latin Extended for PL/DE diacritics. IBM Plex Mono is permitted for IPA, language codes, lemma forms and numeric data only.

The eyebrow — standard section header

11px · 550 · 1.5px tracking · uppercase · #872657 · 8px above its heading. The pattern eyebrow → large serif headline → one-line subhead → one action is the default page header everywhere; do not invent alternatives.

Wordmark is exempt. title-purple.svg (ITC Benguiat, fill #300b4f) is a drawn asset, not type. Never re-set it in Literata, never use Benguiat for UI.
Email is exempt. Georgia body, Arial nowhere. Literata will not load in mail clients.
Minimums. Body 15px, UI labels 12px, reader 17–19px. Nothing below 11px, and 11px only for eyebrows and metadata.
Prohibited

Any system font stack (Cambria, Cochin, Georgia, Times and friends). Arial, Helvetica, fantasy. Per-component font-family declarations — two variables, no exceptions. A serif for a form label; a sans for body prose. A fourth family.

3 · Buttons & states

One primary action per view. Radius 9999px, label 600 weight, transition 160ms ease on transform and box-shadow.

Primary — solid #5A1A74 · hover #48177D + translateY(-1px) + 0 6px 16px rgba(72,23,125,.28) · pressed #3A1462 + translateY(1px) + inset shadow
Secondary — outline #2C2530, fills to solid ink on hover. Moves toward ink, never toward plum.
Tertiary — plum text, hairline border #d8cfd6, or plain text link.
Premium — linear-gradient(135deg,#8F2356,#5A1A74) + inset 0 1px 0 rgba(255,240,250,.28). The only gradient in the product.
Not-yet-satisfiable — outline plum, fills solid the instant the form validates. Full-strength label.
Disabled — background:#e8e2e6; color:#8b8290; box-shadow:none; cursor:not-allowed; opacity:1
Disable for danger, never for incompleteness

An incomplete form keeps a live button; clicking it marks the offending fields and moves focus to the first. A disabled button cannot explain what is missing, so users who get stuck get stuck silently. Destructive and irreversible actions are the exception — Delete Account stays grey and dead until the typed confirmation matches.

Never set opacity on a composited button — the shadow and border fade with it and the edge dissolves. Fade label and fill as separate tokens if fading at all. 38% of a gradient is still the most saturated thing on screen.

Hover uses a state layer (on-colour at ~8%) or a ramp-step darken. Never dim on hover.

Prohibited

Scale on hover. Glow, sweep, ripple or icon-slide on any non-premium control. Gradient text (background-clip:text) anywhere — retire .full-gradient-btn. Two controls leading to one destination. A filled pill for a non-committing action.

4 · Premium

Premium is a material, not a colour. It differs by how it responds to light, not by being louder. It never leaves the ramp.

--premium-gradient: linear-gradient(135deg, #8F2356, #5A1A74);

/* star / badge */
box-shadow: inset 0 1px 0 rgba(255,240,250,.45),
           inset 0 -1px 0 rgba(20,6,30,.30),
           0 2px 6px rgba(72,23,125,.30);
/* hover: gradient 200deg, translateY(-1px), 400ms */
The two inset hairlines are the whole effect: pale top edge, dark bottom edge, reading as struck metal catching room light. Bevel improves at small size; glow never does.
Shine sweep — permitted on the plan card only. Single 900ms pass on hover, highlight rgba(255,252,248,.22), skewX(20deg), blur 6px. No infinite loop — ambient animation on pricing reads as a slot machine.
Confetti — on successful upgrade only, fired client-side off the checkout redirect route. Never on revisit. No schema change needed.
Premium as status — plum 550 text plus the bevelled star. Not bold, not a filled pill, not a button.
Plan limits — grey body text with a plum link. State the cap, not the restriction: "Free covers one language at a time", never "Free plan lets you pick only 1".
Paywall placement — contextual, at the wall: second language, private import, first book finished. Never in onboarding.

5 · Register & jurisdiction

Two registers coexist — bookish-intelligentsia and warm-playful. They are compatible only under a jurisdiction rule, and they never share a screen.

Calm — content surfaces

Reader, library, cards, review, settings, chat, landing hero. Serif, cream, plum. No mascot, no emoji, no illustration, no ambient motion. Motion only as state feedback.

Warm — contentless surfaces

Empty states, errors, 404, offline, loading, auth, onboarding, earned celebration. Mascot and particles live here and only here.

Audience. Self-directed B2–C1 readers who chose Almonium for not being gamified. Nothing may read as a beginner app: no streak threats, no mascot above the fold, no exclamation marks, no emoji, no "awesome".
Voice. Second person, plain, unhurried. State facts and let the reader draw the conclusion. No "exclusive", "top-tier", "excited to have you on board".
Celebration is rationed to three events — first upgrade, book finished, review session complete. A fourth use makes all four ordinary.
Progress is a record, never a threat. Weeks are the unit, the user sets their own target, "No target" is a first-class choice, and no number can be lost.

6 · Emblem, wordmark, motion

Assets. logo.svg (ten blades, ramp steps 1–6) · logo-on-white-circle.svg (seal; art occupies 91% of disc width, 94% of height — preserve that berth, do not add to it) · title-purple.svg (wordmark).
Flat fallback #7D2060 for 16px favicons, email, print, embroidery, monochrome contexts, and any plum ground.
Semantics of the fold. Unfold = one becoming many: loading, discovering, expanding a word into senses. Fold = many becoming one: saving, collecting, committing to memory. Never mixed.
Loader timing. Reach 3–4 blades within 250ms, bloom over the remainder, hold. Never spend the majority of the cycle on a single rotating blade.
Navbar logo navigates home and plays the unfold during the route transition. A logo that only animates is a dead control.
Blade gauge. Static emblem, blades filling discretely, 180ms bloom per blade. For countable units only — review sessions, onboarding, placement, chapter cards. Never for reading position in a book: use a linear bar, since 10% granularity is too coarse and prose is continuous.
Never two progress indicators on one screen. If a labelled step plank is present, no blades.
Wordmark is solid, never gradient, never re-set in a UI face. Lockup: emblem at the wordmark's optical height, gap ≈ one cap-height of "A".
Watermark emblem ≤6% opacity, cropped off an edge. Centred watermarks read as placeholders.
Open licensing item. The wordmark is ITC Benguiat (Monotype), commercial. Confirm the identification, then buy a desktop licence retroactively and keep the receipt. Typeface designs are not copyrightable in the US but font software is, so the exposure is contractual. A Canva origin does not cover trademark use.

7 · Almo & illustration

One octopus, one style, one ink. Nine brains, eight arms for parallel texts, ink for writing, camouflage for register — the animal maps to the product. It stays.

Style. 19th-century engraved plate. Hatching, no airbrush, no gloss, no rim light. Single plum ink #612B5E on transparent, rendered at 2× display size.
Fixed set of 6–8 poses: rest, reading, offering a card, searching, asleep, delight, waiting, greeting. The greeting fans its arms behind it, echoing the emblem's bloom.
Placement. Empty states, errors, 404, offline, loading, onboarding's final screen. Never the landing hero, never the reader, never any surface holding content.
Naming by exposure. Name him in passing in copy ("Almo hasn't found anything here yet"). Never a nameplate, never a "meet Almo" moment.
Avatars. One disc, one fill, and the fill is the tier: free accounts flat #d8cfd6 with an ink mark, members the premium gradient with a cream mark. No ring, no star, no dot, nothing else encoded. Same avatar for every viewer including yourself. The mark is one letter — the first alphanumeric character of the username, uppercased — because there is no first or last name to take initials from. Optional set: five engraved animals in the same hand and ink — owl, fox, stag, whale, hare. No octopus avatar; that silhouette is Almo's alone. Retire custom photo uploads: moderation, storage, GDPR deletion and cropping cost more than a barely-social profile returns.
One illustration style in the product. The cartoon avatar set, the coral airbrushed octopus and the AI hard-hat render are all withdrawn. Commission once; AI may sketch, a human finishes.
Consistency method. No seed parameter exists in GPT-Image-1, so text prompts never reproduce a character. Generate all poses in one character-sheet render and crop them apart; for additions, upload the approved original as reference — never chain from the newest output, or drift accumulates. Vector-redraw the final set.

8 · Surfaces & layout

The card is the atom. White on cream, radius 24–28px on panels, 12–18px on nested blocks, 0 1px 3px rgba(0,0,0,.1), 0 1px 2px -1px rgba(0,0,0,.1). Every panel is a card because every object in the product is one.
No inner shadows. Inner shadow reads as recessed and contradicts a raised panel. To increase presence, deepen the outer shadow.
Flex/grid with gap for every sibling group. Never margin-spaced inline siblings.
Language edge rail — a 3px rule under the navbar in the active language's hue, with the code badge sharing that hue. The only place a language colour may be large. User-overridable from a fixed set of ~8 muted hues.
Interest pills may be multicolour — user-owned content, one tab, drawn from a fixed 8-hue set at consistent saturation and lightness. This palette never leaks into learning data or product chrome.
Particle field — auth, onboarding, upgrade success only. Gated on prefers-reduced-motion. Never behind text.
Spines — thickness bounded 34–66px across the whole page-count range. Private imports get identical footprint to library books, distinguished by a dashed edge and a "Yours" mark, never by being shrunk.
Reader. Body #33292E at 17–19px; saved word #5A1A74; marginalia #6C1D6A at 80%; chapter headings #2C2530. Marginalia sits in a true margin on desktop with hairline leaders; on mobile it becomes a sheet that pushes text up. Never occlude the sentence being read.

9 · Email

Ink #2C2530 shell, cream #F9F6F5 content card, Georgia body at line-height:1.55, body colour #33292E.
Buttons solid #5A1A74. Outlook strips gradients, so only the subscription email carries one, with bgcolor="#5A1A74" beneath as fallback.
Wordmark as 2× PNG with the name in alt. SVG does not render in most mail clients.
Footer contrast on ink: tagline #a99aa8, unsubscribe #c9c0cc. Unsubscribe must be conspicuous — CAN-SPAM and GDPR.
Tables and inline styles, not divs. Round corners need VML in Outlook or accept squares. Every send needs a plain-text part. Test Gmail iOS and Outlook for dark-mode inversion.
Copy. A transactional email owes the fact, the action, and what happens if you do nothing. Receipts owe price, renewal date, and where to cancel. No filler line to fill a card; no restating what the button says.

10 · Onboarding

1 Welcome → 2 Language → 3 Level → 4 Interests → 5 Profile → 6 Almo's greeting

One question per screen. Back works everywhere. State persists per step, so a drop-off resumes in place.
No paywall step. Removed entirely; the ask moves to the contextual wall.
Language. Target first, in cards, large — it is the decision the user came to make. Native language is detected from locale and demoted to one correctable line. Feature availability renders per card from languageFeatures, not a hardcoded list; today only EN and DE carry extras.
Level. Behavioural sentences lead, the CEFR code is a quiet monospace tag. "I'm not sure" is a dashed sibling option, not a link, routing to eight sentences of ascending difficulty; level assigned at the first two consecutive misses, skippable, defaulting to B1. Settings must use the same descriptions.
Interests. 6–8 chosen from ~30. Soft floor via the outline→solid button, no hard block.
Profile. Both fields ship pre-filled and the subhead says so, which makes Continue the skip. No second Skip button — two controls to one outcome is worse than one. Show the real initials avatar rather than an empty upload well.
Final screen is Almo greeting, not a form. Converts "setup finished" into "let's begin", and is where the mascot earns his introduction.

11 · Accessibility & honesty

4.5:1 on all body text, 3:1 on large text and UI boundaries. Check every cream-on-ink and grey-on-cream pair, including footers.
Status is never conveyed by colour alone — pair with text, icon or position.
Hit targets ≥44px on touch. Visible focus ring on every interactive element.
All ambient motion respects prefers-reduced-motion.
Status must never look like action, and an action must never be labelled with a state. A button reading "Unhide" cannot tell the user which state they are in — use a labelled switch.
Icon-only controls get labels wherever the action is not universally understood (share, QR, copy link).

12 · Dark mode

Every law above holds in dark; what changes is which value plays which role. Full token set, component specs and specimens live in the dark mode rulebook, which this section does not restate. The four rules that bind light-mode work:

Author against tokens, never hexes. A component that writes #fff, #F9F6F5 or a ramp step directly cannot be themed and will be rejected. The theme is one flip on [data-theme="dark"].
Nothing inverts literally. White cards do not become black cards; elevation on dark is lightness plus a hairline, not shadow.
The ramp extends at its light end — #E0C4EE, #CBA3E0, #B07BD0, #9059BC, plus rose #D98BA8 for eyebrows. No new hues. Law 1 stands.
Brand assets need dark counterparts, not filters: cream wordmark, re-inked Almo. The emblem is unchanged.
Known open questions
Which layer owns tokens — Tailwind config, Less variables, or Taiga UI — is undecided. The type and colour consolidation must land in whichever is authoritative.
Discover, Review and Chat have never been reviewed. Rules here may need amendment once seen.
